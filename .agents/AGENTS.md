# プロジェクト規約

このプロジェクトは `pmp-2026-cheatsheet` リポジトリのワークスペースです。
コード開発だけでなく、仕様設計、ドキュメント作成、レポート管理も行います。

## フォルダ構成の役割
- `/src`: プログラムのソースコード。
- `/docs`: プロジェクト関連ドキュメント（Markdown形式推奨）。
  - `/docs/specs`: 要件定義・基本設計・詳細設計などの仕様書。
  - `/docs/reports`: 調査レポート、動作検証結果などの報告書。
  - `/docs/manuals`: 手順書、操作マニュアル。
  - `/docs/assets`: ドキュメントに埋め込む画像やPDFなどのバイナリファイル。
- `/assets`: アプリケーションそのものが直接読み込んで使用する静的素材。

## 開発・Git運用ルール
- **言語**: ドキュメント、コミットメッセージ、プルリクエストは日本語を基本とします。
- **Gitブランチ運用**:
  - 新機能/修正のブランチは `feature/<概要>` または `fix/<概要>` の形式で作成してください。
- **コミットメッセージ (Conventional Commits)**:
  - `feat:` 新機能・新規ドキュメント
  - `fix:` バグ修正や誤記修正
  - `docs:` ドキュメントのみの変更
  - `refactor:` リファクタリング
  - `chore:` 補助ツール・ビルド等の変更
- **ドキュメント管理**:
  - ドキュメント内の画像は `docs/assets/` に配置し、相対パスで参照してください。
  - バイナリファイルは Git LFS で管理します。
