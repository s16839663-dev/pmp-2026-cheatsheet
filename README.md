# pmp-2026-cheatsheet

住宅ローン支払いシミュレーション用プロジェクト (`pmp-2026-cheatsheet`) です。
このリポジトリでは、ソースコードとともに関連する設計仕様書、調査報告書、運用マニュアル等のドキュメントを一元管理します。

## プロジェクト構成

```text
├── src/                       # ソースコード
├── docs/                      # ドキュメント
│   ├── specs/                 # 設計書・仕様書
│   ├── reports/               # 調査レポート・検証結果
│   ├── manuals/               # 手順書・マニュアル
│   └── assets/                # ドキュメント内での参照画像・PDF
│       ├── diagrams/          # 構成図・シーケンス図など
│       └── screenshots/       # 画面キャプチャなど
└── assets/                    # アプリ本体の静的リソース
```

## ドキュメントへのインデックス
- **仕様書・設計書 (`docs/specs/`)**
- **調査報告書・レポート (`docs/reports/`)**
- **マニュアル (`docs/manuals/`)**
